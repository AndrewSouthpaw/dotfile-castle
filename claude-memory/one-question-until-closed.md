description: In a design dialogue, answer the follow-up and stop; ask the next question only after an explicit go-ahead
metadata:
  type: feedback
---

When Andrew replies to a design question with a follow-up or correction, answer it and stop. Don't append the next question.

**Why:** "I'm not done yet with this question. Stop running on to the next one."

**How to apply:** Each message ends on the question he's still working. Move on after "yes", "go with 2", "next". Related: [[show-research-before-questions]].
