description: Get each step working before the next, e.g. each version in an incremental upgrade
metadata:
  type: feedback
---

Fix each error before moving to the next step. Don't skip ahead hoping a newer version fixes the current issue.

**Why:** Andrew wants a working state at each step. Jumping from one SDK version to the next without fixing the first was called unacceptable.

**How to apply:** In incremental upgrades (SDKs, libraries), get each version green before the next one.
